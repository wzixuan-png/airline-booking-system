Main functions include searching scheduled flights by origin, destination, and date range, booking a selected flight, generating an invoice with a unique booking reference, checking trips by passenger email, and cancelling a booking by booking reference. The system also prevents bookings when a flight is full.

To run locally, install dependencies with npm install, create a .env.local file with MONGODB_URI and MONGODB_DB, then run npm run seed to load scheduled flight data. Start the application with npm run dev and open http://localhost:3000.
